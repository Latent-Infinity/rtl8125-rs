# Recommended run length: 4 hours.
# Pass criteria:
#   - No KASAN / UBSAN / lockdep / kmemleak reports during the run
#   - No kernel panics
#   - No `BUG:` lines in the harvested console log
#   - Driver remains loaded and the interface remains carrier-up
#
# The control-plane focus (ethtool, netlink, ifreq, socket options)
# is appropriate for this driver — most attack surface is in the
# control path. The data path is covered by `ci/check_packet_mutation.sh`
# and the 24-hour active soak.
