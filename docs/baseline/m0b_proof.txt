Host I226-V enp4s0 (0000:04:00.0) ↔ Cat6 ↔ RTL8125 (0000:03:00.0 → VFIO →

10.0.0.0/24 loop — host management stays on Wi-Fi `wlp6s0`, k3s uses
that exclusively.

## Link facts

- Negotiated: 2500 Mb/s Full-Duplex, both ends.
- Flow control: host I226-V RX/TX on (autoneg landed RX-only at the
  last link-up event); guest RTL8125 RX/TX off (no pause-frame
  negotiation on r8169 side).
- EEE: I226-V disabled locally; RTL8125 enabled-but-inactive
  (advertised but not active because the partner doesn't enable).
- Jumbo (9000 MTU): works end-to-end after MTU set on both sides.
  Verified by `ping -M do -s 8972`: 5/5, 0% loss after a brief
  PHY-renegotiation settling period (~1–2 s post-mtu-change).
