## Runbook corrections required (docs/M0a_TO_M1_RUNBOOK.md Phase 7)
The Phase 7 recipe as written does NOT work in this environment:
1. `LLVM=1` is WRONG — the guest kernel is GCC-built (gcc 15.2.0). LLVM=1
   forces clang for the C module-glue (.mod.o) and clang rejects GCC-only
   flags (-mindirect-branch=thunk-extern, -mpreferred-stack-boundary=3, ...).
   Correct: build with the default CC (gcc); drop LLVM=1.
2. The `module!{...}` snippet is missing `authors:` and `description:` and a
   trailing comma; the macro fails with "expected `,`". Use the field set from
   samples/rust/rust_minimal.rs (type/name/authors/description/license, each
   comma-terminated).
3. `echo 0 | sudo tee /sys/kernel/debug/kmemleak` is not a valid kmemleak
   command. Use `echo scan` to force a scan.
4. Phase 7 has an unstated prerequisite: the guest needs the build toolchain
   installed (rustc-1.93, bindgen, build-essential, dwarves) AND the rust/
   subtree staged. Neither shipped on the guest.
