1. **§6.3 invariant clean** under sustained traffic: `tx_received=1,784,150 = tx_consumed+busy+drop = 1,784,145+0+0`, gap=5 (in-flight). No drops, no busy-exception spikes.
2. **5.78 M packets handed to the stack** RX side, zero rx_dropped_error.
3. **MSI-X delivering to CPU1** (vector#0, IRQ 62), 832 K IRQs during the run = ~83 K IRQ/s peak.
4. **ASPM Disabled in LnkCtl** — chip-side `force_aspm=0` default did its job; `aspm_force_off=1` operator-intent reached the driver (dmesg confirmed earlier).
5. **TSO/TX-CSUM both `on`** at MTU 1500 as expected; SG on; RX-CSUM on.
